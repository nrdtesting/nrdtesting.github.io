HOW TO UPLOAD THE NEW SITE (v2)
================================

WHAT THIS FOLDER IS
  NRDV2 is the complete new website. Every file the site needs is here.
  The old NRDTESTING folder is now retired; don't upload from it anymore.

STEP 1 - CLEAN THE REPO (one-time, recommended)
  The repo has junk from past uploads (a nested NRDTESTING folder, stray
  files like "claude", "test", "settings.local.json", root-level .css
  copies). To delete a file/folder on GitHub:
    - open the file in the repo
    - click the trash-can icon (top right of the file view)
    - commit
  For the nested NRDTESTING folder: open it, and delete files inside it
  until it disappears (GitHub removes empty folders automatically).
  If that is tedious, skip it; the new files below will overwrite what
  matters, and strays are only clutter.

STEP 2 - UPLOAD EVERYTHING FROM INSIDE THIS FOLDER
  Go to:  https://github.com/nrdtesting/nrdtesting.github.io/upload/main

  IMPORTANT: open the NRDV2 folder in File Explorer first, press
  Ctrl+A to select ALL its CONTENTS (files AND the css/js/images/assets
  folders), then drag the selection onto the GitHub upload box.

  Do NOT drag the NRDV2 folder itself. Dragging the folder creates
  nrdtesting.github.io/NRDV2/... and nothing will work. Drag what is
  INSIDE it.

  Commit. Wait ~1 minute for GitHub Pages to rebuild.

STEP 3 - VERIFY
  - open https://nrdtesting.github.io/ in Incognito (or Ctrl+F5)
  - you should land in the 3D castle; scroll to dive
  - check https://nrdtesting.github.io/js/home.js exists (not 404)
